# 事后复盘

[English](README.md) | 中文

事故记录：一个 bug 到达了它不该到达的地方（真实用户、已合并的改动、一次发布），而有趣的部分是*为什么我们的流程让它漏过去了*，而不只是那一行修复。

事后复盘不是 [Agent Note](../../.agents/notes/README.md)（它记录一个刻意的设计决策及其被否决的备选，或提案未来工作）。它是面向过去的失败记录：什么坏了、机制、为什么每道安全网都漏了它，以及为让同类 bug 下次响亮失败而加的具名护栏。

当 bug **微妙**（机制不明显，细心的工程师会艰难地重新推导）、**系统性的**（它漏过去的原因是测试/工具/约定的缺口，而非一次性笔误）、且**重新发现的代价高**（它花了真实调试时间，还会再花）时写一份。链接它催生的护栏（测试、`AGENTS.md` 规则、Agent Note）。

每份事后复盘以**执行摘要**开头：一段忙碌读者三十秒能吸收的短段落 —— 什么坏了、用大白话说的根因、它为何漏过去、以及持久教训 —— 之后才是详细的摘要 / 时间线 / 根因 / 护栏章节。
